# Python fundamentals quiz prep (quiz on 15 October)

Open this folder in VS Code (File > Open Folder) and select a Python 3.9 kernel at the top right of each notebook.

Suggested order:

1. `01_learn_and_practice.ipynb`: 10 topics split into 45 small steps, 211 exercises. Each step has a short explanation, a demo cell, and exercises from easy to harder with folded solutions (click "Solution" to open). Predict first, then run.
2. `02_exam_questions_by_topic.ipynb`: 115 quiz-style questions, topic by topic, each topic going from level 1 (basic) to level 3 (hard), plus a final mixed hard section and a score tracker. Do not run the code; answer in your head or on paper, then open the answer.
3. `03_mock_exam_timed.ipynb`: one full mock quiz, 15 questions in 15 minutes. Run the timer cell first and the result cell at the end.
4. `quizlet_import.txt`: 122 flashcards for Quizlet.

## Importing into Quizlet

Create a new set, choose Import, paste the content of `quizlet_import.txt`, then set:
- Between term and definition: Custom, `;`
- Between rows: New line

Code that has several lines is written on one line, with ` ⏎ ` marking each line break.
Answers show the value with its type, e.g. `'32' (str)`. Strings are in quotes, so you can see the difference between `'5'` and `5`.
